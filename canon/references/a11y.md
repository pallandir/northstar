# Accessibility
Load when: building any interactive UI, or before shipping, since the WCAG 2.2 AA floor applies to every mode.

## Principles
- WCAG 2.2 AA is a floor, not a score. These rules are marked not allowable and no brief can lower them.
- Any NS-A11Y error caps the overall score at 6 whatever else is good.
- Use native elements first, then library primitives that render them. ARIA fills gaps and does not replace semantics (NS-A11Y-SEMANTICS).
- Everything operable by pointer is operable by keyboard, in a logical order, with visible focus (NS-A11Y-FOCUS-VISIBLE).
- Colour is never the only signal. Contrast is verified on tokens (NS-A11Y-CONTRAST).
- Motion is optional for the user (NS-A11Y-REDUCED-MOTION).
- Content reflows at 320 CSS pixels wide and at 400% zoom with no loss.
- Test with a keyboard, a screen reader pass and zoom, not only with a detector.

## Do
- Contrast: text 4.5:1, large text 3:1, UI components, focus rings and graphics 3:1 against neighbours.
- Check hover, disabled hints, placeholder and text over images.
- Focus: `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }`.
- The ring has 3:1 contrast and is not hidden by `overflow` or fixed headers (WCAG 2.2 focus not obscured).
- Targets: at least 24 by 24 CSS pixels (AA), 44 by 44 for touch.
- Grow the hit area with padding or a pseudo element, with 8px between small targets (NS-A11Y-TARGET-SIZE).
- Semantics: `button` for actions, `a` for navigation, `label` bound to every `input`, `fieldset` and `legend` for groups, landmarks (`header`, `nav`, `main`, `footer`), one `h1`, headings in order, `alt` on images (empty `alt=""` when decorative).
- Overlays and menus: library primitives (shadcn on Radix, Reka, Bits, Kobalte, Angular CDK) or native `dialog` and `popover`.
- They bring focus trap, Escape, return focus and `aria` correctly (NS-LIB-OVERLAY).
- Icons: from Lucide or another library, with `aria-hidden` when beside text and an accessible name when alone.
- Call `resolve_icon` (NS-LIB-ICON).
- Forms: visible labels, `autocomplete` tokens, errors linked with `aria-describedby`, `aria-invalid`, error text that names the fix, and no re-entry of data already given.
- Dynamic updates: toasts and status messages go in a live region (`role="status"`), which a library such as Sonner handles (NS-LIB-TOAST).
- Motion: gate with `prefers-reduced-motion`, give controls to pause anything that moves over 5 seconds.
- Zoom and text: never disable pinch zoom, size in `rem`, allow text spacing overrides, and use `100dvh` carefully.
- Dragging has a click alternative.
- Add a skip link as the first focusable element on pages with navigation.
- Provide a text alternative for charts, such as a table or summary, and do not rely on colour alone to separate series.
- Give video captions and audio transcripts, and keep timeouts adjustable or absent.

## Avoid
- `outline: none` with no replacement (NS-A11Y-FOCUS-VISIBLE).
- Clickable `div` or `span`, inputs with no label, images with no `alt` (NS-A11Y-SEMANTICS).
- Light grey on white, low contrast placeholders, text over busy imagery with no scrim (NS-A11Y-CONTRAST).
- Small icon only buttons with no padding (NS-A11Y-TARGET-SIZE).
- Unconditional autoplay, parallax and looping animation (NS-A11Y-REDUCED-MOTION).
- Hover only disclosure, tooltips that cannot be reached by keyboard, placeholder as the only label.
- `tabindex` greater than 0.
- Colour only status.

## By mode
| Mode | Emphasis |
| --- | --- |
| operate | Target size is an error. Full keyboard paths, shortcuts that do not clash, table and form semantics, live regions for async results |
| read | Heading structure, link text that makes sense alone, 200% text resize, high contrast, print and reader view friendly |
| persuade | Contrast on every CTA and over hero imagery, accessible forms, captions on video, motion gated |
| experience | Expressive visuals still need real semantics, contrast and focus, a reduced motion fallback for every effect, a keyboard route past canvas and scroll effects |

## Checks
- Tab through the page: every control is reached in order and focus is always visible (NS-A11Y-FOCUS-VISIBLE).
- Contrast pairs pass in light and dark (NS-A11Y-CONTRAST).
- Targets measure at least 24px, 44px on touch (NS-A11Y-TARGET-SIZE).
- Emulate reduced motion and confirm nothing moves unprompted (NS-A11Y-REDUCED-MOTION).
- Static scan finds no non semantic interactive elements, unlabelled inputs or missing `alt` (NS-A11Y-SEMANTICS).
- Page works at 320px width, 400% zoom and with text spacing increased.
- Screen reader names for buttons, icons, fields and errors are meaningful.
